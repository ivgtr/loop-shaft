# 品質・標本・序盤装備・探索発見

## 目的と境界

安定した仕事の自動化を維持し、「普通の採掘でも少し得をする」「出た装備を試す」「見つかった手掛かりを調べに行く」を重ねる。行動を変える余地が目的であり、滞在時間や抽選回数を無限に増やす設計にはしない。通常鉱石の基礎収量・重量・基本査定額、購入費、研究費、Core残量は下げない／引き上げない。必須機能をレアドロップでしか解放できるようにはしない。

採掘 → 物理貨物 → 回収 → 積載 → 発送 → 地上での荷下ろしという所有権を維持する。Player / Miner / Boreの通常報酬と新規発見は `rollMiningLoot` を共有する。新しい抽選は投資・研究・Coreそのものを倍化しない。

## 抽選と有限報酬

| 内容 | 基本設定 | 救済・制限 |
| --- | --- | --- |
| 通常鉱石の品質 | 通常85% / Fine12%（1.5倍）/ Pure3%（3倍） | 同じ階層で通常品質が12回続いた次の破壊はFine以上。1破壊分の通常鉱石だけに適用。重量は変わらない。 |
| D-030のField Tool | 1破壊ごとに5% | 初回6破壊以内、その後は前回生成から16破壊以内。地上未納品でも生成時点でカウントする。 |
| Field Toolの内容 | COMMON75% / RARE25%、level1・追加効果一つ | Fossil Pick / Lightweight Pick / Survey Pickの3方向。既存の装着・比較・所有権移動を使う。上位装備の分布は変更しない。 |
| 未鑑定化石の状態 | Intact82%（1.5倍）/ Pristine18%（3倍） | 種類は既存の深度別化石抽選を使う。品質は採掘時に固定し、セーブに保持する。既知の歓迎濃集部の化石は未鑑定化しない。 |
| 化石向け鉱脈の救済 | fossilWeight 0.45以上 | 化石が7回続けて出なかった次の破壊は化石（Core・初研究・初遺物保証を優先）。生成済み化石でリセット。 |
| 新しい探索の手掛かり | 対象階層の6回目と18回目に一つずつ露出 | 異なる既存地点に配置、最初の一つは可能なら入口側を避ける。現地2回／3回の破壊で一度だけ採取。D-650には追加しない。 |

品質の85/12/3は救済前の確率。救済込みの平均倍率は1.12に固定されない。実装した256 Seed × 80破壊のプローブでは、丸め前・等重みの平均品質倍率は約1.1284倍。これは運搬を含む収益倍率ではない。

品質・手掛かり・Field Toolの乱数はFloor Seedとローカル進捗に基づく独立した値で、既存の共有RNGを読み進めない。既存の一般ドロップ抽選は従来どおり共有RNGを使用する。描画・ホバー・プレビューはいずれも乱数を消費しない。

Field Toolの追加効果は既存効果を利用する。Fossil Breakerは化石向け鉱脈の**実際のプレイヤー打撃**にも適用する。Light Frameは説明どおり荷物を持っている時の速度に適用し、空荷を無条件に高速化しない。比較画面にはLoaded speedと化石向け対象への打撃も表示する。Research Prismは研究カテゴリの相対的な重みを増やす効果であり、絶対当選率への加算ではない。

## 手掛かりからの探索

通常生産・既知の歓迎濃集部・新しい手掛かりは別物。手掛かりの生成や消費で通常鉱脈の量・通常抽選率を下げない。時間切れ、ログイン期限、短周期の再出現はない。通常岩が再生中でも手掛かりは同じ場所に残る。

Metal flecksは高価値品、Fossil outlineは未鑑定化石、Layered crystalは研究品。深度に見合った種類から選ぶ。手掛かりは当たりカテゴリと残り作業量まで示し、未鑑定標本の種類・状態は先に明かさない。採掘員のRARE/RESEARCH/ANYも、公開されている手掛かりの価値を評価できる。機械だけ抽選率を下げたり手動クリックを強制したりしない。

Boreは通常鉱石・既知濃集部・新しい追加報酬を含めた最大重量を破壊前に予約し、容量不足を理由に生成済みの当たりを捨てない。

## 鑑定・重複・フィードバック

未鑑定化石の貨物名はUnidentified fossil、公開査定目安は最低42 Scrap。種類・保存状態・最終額は地上荷下ろし時にだけ表示する。Central ElevatorとFreightは共通の `appraisePhysicalCargo` を通る。一個ずつの開封ボタン、手数料、再抽選は追加しない。

Archive → RECENTには初発見、Pristine、Pure鉱石の納品、装備の鑑定、復元結果を最大12件残す。これはRun内履歴で、Coreや図鑑の恒久記録とは別。Pure鉱石は一便単位でまとめる。初装備・別のビルド候補・初標本などを優先する短い通知を出し、小当たりで上書きしない。表示待ちは最大4件・期限8秒、効果音にも短い抑制を設け、作業は停止しない。

未発見の化石はArchive → FINDSから、同系統の**納品済み重複5個**で復元できる。殻系（Trilobite / Ammonite）と脊椎動物系（Fish / Tooth / Vertebra）を分離し、深い化石は対応深度の到達記録も必要。最初の一個と過去の納品数は消さず、使用済み重複数を別に記録する。復元は図鑑記録のみで、Scrap・Data・Core・パッシブは増やさない。確認画面に支払うもの／残るもの／得るものを固定し、直接コマンドや連打では確認を迂回できない。

## 探索へ切り替えるためのPorter hold

LIFT → SHIP → Porter pickup holdで新規回収のみ保留する。既に持った貨物は運び切り、床の貨物は消さない。手動のRESUMEか階層移動の完了で回収を再開する。保留状態はセーブに保持し、SHIPと空のリフトの状態表示で分かる。

この操作は初周試走で見つかった「移動準備中もPorterが次の荷物を拾い続け、床の滞留がなくなるまで空荷のリフトを作れない」問題への明示的な制御。ウィンドウを開いただけで黙って全自動化を停止するものではない。

## グラフィック契約と将来の拡張

現行の画像・編集元は [発見アート](./discovery-art.md)、分岐の統合と打撃演出は [発見描画の統合](./discovery-visuals.md) を参照。

`deriveSemanticRenderState().discoveries` の `signal / stage / remaining` に従い手掛かりを描く。画像の露出段階は残作業の投影であり、新しいゲーム状態ではない。再生中も採取済み跡を残し、装飾用の時刻や乱数で状態を進めない。

物理貨物の `quality / specimen` は床・手持ち・リフト・集積所・トロッコ・Freight・Bore出力まで同一の所有物に付随する。共通アトラスと受け渡し座標を使い、品質は色だけでなく面の形で区別する。未鑑定品は種類・保存状態・最終価値を漏らさず、鑑定後にだけ正体を表示する。

地形全体の掘り進め・隠し通路・地形破壊・工具別の操作方式は今回の実装に含めず、現状の識別性を実物の画像で確認した後の別機能とする。

## 保存と既存プレイ

v6の保存キー／versionを維持。品質、標本の確定結果、階層ごとの保証・有限進捗、化石救済、重複使用数、直近鑑定、Porter holdを追加し、数値範囲と種類を復元時に検証する。貨物の品質は定義から計算し、標本も保存状態から再構成するため、不正な任意倍率を受け入れない。

従来のv6では新システムのカウンターは未開始として導入する。これは一度だけ新しい手掛かりを得られる意図的な移行で、保存後の再読込で補充しない。既知濃集部・Coreの旧移行規則はそのまま。既存の貨物・装備・所持資産は失わせない。Rebootでは新しいRunの手掛かりを生成し、恒久図鑑・復元済み記録・使用済み重複数は保持する。装備の保持は既存Legacy Lockerの規則に従う。

## 計測と人間の確認

`npm run balance:report` で `balance-results.json` を更新する。通常のテストは文書を書き換えない。ファイルハッシュ、全Seed、方針と数値を同じファイルに残す。

- 12 Seed × 360秒の納品収益。装備を同じ条件で付与し購入費は除く。近場／銅／化石固定、既知濃集部探索、新手掛かり探索を比較する。
- 16 Seed × 2方針の新規0 Scrapから初2 Core納品まで。通常コマンド、物理物流、実際の鑑定を通し、最初に届いた工具を装備する。移動前は公開されたPorter hold操作を使う。古い試走とはこの方針も異なるため、単なる品質上昇だけの効果として比較しない。
- 256 Seed × 80回の抽選プローブ。品質と序盤装備の保証・分布を確認するが、時間や納品収益の証明にはしない。

初周の参考試走32本すべてが到達。自動化先行の中央値約29.7分、最大約36.2分。探索先行の中央値約27.5分、最大約40.7分。最初の品質上振れは約2.6～104.9秒、最初の装備鑑定は約5.3～11.3分。この値は迷い・入力遅延・読む時間のないスクリプトの結果で、初周45～60分という人間向け仮目標の達成を示さない。

人間は、(1)手掛かりの存在と対象を見つけられるか、(2)通常報酬でも購入を進められるか、(3)拾った工具を試したくなるか、(4)納品を待つ意味を感じるか、(5)新規回収保留が必要な場面で見つけられるか、(6)長時間の通知や重複が雑音にならないかを確認する。主観的な面白さ、3時間の継続性、実機スマートフォンでの見やすさは自動検証済みとしない。

# D-001 visual refinement

D-001のみを対象とした画面の仕上げ。ゲームルール、保存形式、世界座標、hit領域、床の接地点、アニメーションのフレーム数・時刻・所有レイヤーは変更しない。

## 変更

- 既存の岩盤の大きな面を残し、孤立したピクセル模様と背景のコントラストを抑える。
- 左右の坑道に異なる天井断面を作り、低ディテールの暗い奥面を広げる。
- 既存の梁、筋交い、灯りのピクセルを再利用。柱だけを延長し、木目や金具を引き伸ばさない。
- 床と接地点を維持し、人物の足元を横切っていた装飾レールを除去する。
- 鉱脈の損傷シルエットに沿う薄い岩の縁を追加。Scrapの金属とCopper・Fossilを区別する。
- PlayerとPorterの服、ヘルメット、通常Cargoの配色を既存パレット内で整理する。Porterの既存の自動化用青緑は維持する。
- 初回ガイドの詳細説明は保持し、自動で進行する作業の頭上ラベルだけを非表示にする。操作待ち・停止理由は残す。
- D-001では未解放の研究・Engineer・FreightをHUDから省き、使用可能になれば表示する。
- 画面全体が収まるPC表示でCanvasを2倍・3倍の整数倍率にする。D-030以降と小さい画面の既存レイアウトは変更しない。

## 素材の再生成

`npm run assets:d001` は既存の `process-d001-assets.mjs` に続けて `refine-d001-assets.mjs` を実行する。後段だけを繰り返し適用しない。生成元は削除・上書きせず、runtime PNGもコミットする。ImageMagickは素材制作時だけに必要で、通常のbuild・testには追加しない。

後段は固定の座標・既存パレットで処理し、半透明の輪郭、発光halo、ランダムな粒子や作業員を追加しない。PNGの版を更新し、古いHTTPキャッシュが混在しないようにする。

## 確認

`tests/initialGuideOverlay.test.ts` で表示する操作案内・停止理由と非表示の作業状態を検査する。

`tests/e2e/d001-visual.spec.ts` はブラウザでPNGの寸法・パレット・alphaを読み、初期画面から実操作で採掘→回収→積載→SEND→換金を確認する。初期・採掘待機・積載の画面はPlaywright reportへ添付する。3倍表示とD-030の既存HUD・幅も確認する。ImageMagick依存のテストは追加しない。

既存のゲーム・操作・保存・フォールバック検査はそのまま実行する。画面キャプチャは完成したゲーム体験の人手評価を代替しない。

## 残す範囲

全モーションの人体・道具の描き直し、カメラや操作位置の変更、スマートフォン縦持ち専用レイアウト、D-030以降の素材展開はこのPRには含めない。まずD-001の空間・明暗・情報量を比較できる単位として仕上げる。

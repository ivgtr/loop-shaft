# 発見のピクセル素材と完成条件

## 今回の範囲

PR #16 の有限手掛かり・品質・鑑定・物理物流を描画へ接続する第一段階。D-001 の鉱脈、共通貨物、手掛かりの母岩、リフトの格子扉、Archive の標本を実装する。抽選率、価格、収量、重量、保証、採取所要回数は変更しない。

装備ごとのキャラクター素材、設備の全状態差分、深度別背景の新作、横穴探索はこのPRの完成範囲に含めない。以下の制作表で未制作と区別する。現行の工具の向き・収集動作・積載動作は維持し、全モーションの描き直しを完了したとは扱わない。

### 座標・レイヤー契約

すべて整数ピクセル、アルファ0/255、輪郭もパレット内。拡大はnearest-neighbor、半透明の発光・グラデーション・ランダム粒子を素材へ追加しない。アトラスの行末の未使用セルは透明。

### 状態との対応

`src/render/discoveryVisuals.ts` が素材選択の正。母岩は `deriveSemanticRenderState().discoveries` の `signal / stage / remaining` のみを使う。残量0はSPENTの抽出跡で、通常岩のHP・再生時刻によってSEALEDへ戻らない。未公開の手掛かりには母岩を描かない。

貨物は全輸送区間で `drawD001Cargo()` と `cargoSpriteFrame()` を共有する。Normal/Fine/Pureは同じ12×10セルかつ同じ外接範囲内で金属面・輪郭を変え、重量差を示唆する巨大化はしない。集積所・トロッコ・Freight・Bore・Crew貨物も同じ素材を使うが、これらの設備本体の全面的な素材化は未実施。

未鑑定判定を種類・保存状態・equipmentSeedの参照より先に行う。隠された種類と保存状態を変えても同じセル・同じ表示優先度になる。鑑定直後の既存通知には、実際の `SPECIMEN_APPRAISED` イベントから初めて標本画像を表示する。鑑定結果を先読みして準備する画像用抽選はない。

Archiveには現物の鑑定時に限り `bestSpecimenGrade` を記録する。後から普通の個体が届いてもPristineを失わない。これは収蔵履歴であり、別の採掘状態ではない。v6セーブの任意項目で、古い記録の保存状態は捏造せず通常標本として表示する。復元だけのcount=0記録には現物の保存状態を与えない。後日現物が届いた場合は現物の展示へ変わり、RESTORED履歴は残す。

### 背景との区別

操作対象には連続する輪郭、岩の稜線、地面との隙間を使う。鉄くずは水平に割れる板、銅は硬い外殻と太い鉱床、化石向けは層状の母岩。背景へ同じ露出化石・同じ形の結晶・採掘可能に見える独立岩を飾りとして足さない。照明は現場のランプに限り、発見の常時点滅は使わない。無彩色での差分は機械検査に加え、添付スクリーンショットで確認する。ただしピクセル差の存在は人間の識別率の証明ではない。

## 検証と人間の完成判定

`npm run assets:check` / `npm run typecheck` / `npm test` / `npm run build` / `npm run test:e2e`。

単体テストはパレット・全PNG寸法・75コマ・サイズ予算・無彩色差・品質の等寸法・クリック領域・未鑑定情報の非参照・輸送時の共通セル・SPENTの再読込・中央とFreightの収蔵記録・復元と現物の区別を検査する。既存の物流・保存・品質・バランス試走も残す。

Playwrightの追加ケースは320 / 390 / 1280pxの実ゲームとArchiveを撮影し、実際のCanvasのdrawImageの切り出し座標を検査する。別ケースでPure鉱石を実際に回収・手持ち・積載・上昇・換金し、再読込で再報酬がないことを確認する。追加4ケースはChromiumとWebKitの両エンジンで実行する。WebKit自動実行はiPhone実機や製品Safariそのものの検証とは区別する。

ローカルの画像確認はブラウザのlocalhost接続が制限されるため、同じGameRendererとPNGをメモリ上のページへ読み込んで行った。操作E2Eの結果はGitHub Actionsの最終ヘッドを参照する。描画負荷の参考値は `discovery-render-report.json`。固定GameStateに対するrender呼出しのCPU時間で、GPU表示完了、実機フレームレート、熱制限を含まない。

人間による次の確認は未実施であり、機械テスト成功をもって面白さや見やすさの完成とはしない。

- 説明を開かず鉱脈3種と手掛かり・抽出済みを見分け、Pureや未鑑定品の輸送先を追えるか。320px / 390px / PC、無音・無彩色も確認する。
- 初周で品質上振れや鑑定に気づくか、次に掘る場所・装備を変えるか。有限の手掛かりを採り終えた後も次の層や投資へつながるか。
- 2周目以降の低位装備・重複品・上位装備の意味を実プレイで確認する。テンポの不満へ短命イベントや追加抽選で応急対応しない。
- iPhone Safari / Android実機で操作、描画負荷、読み込み失敗、再開を確認する。工具と荷物の持ち位置・積載瞬間の自然さは次段階の作画の受け入れ条件に含める。

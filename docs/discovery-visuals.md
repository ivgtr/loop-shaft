# 発見描画の統合

PR #17 / #18 の分岐を、main の PR #19 / #20 の素材・装備・物流描画へ統合する。現行画像の編集元と再生成手順は [discovery-art.md](./discovery-art.md) に一本化する。

## 残す実装

- 鉱脈・手掛かり・貨物・図鑑は `art/d001/discovery-sprites.json`、装備と物流設備は `art/d001/work-sprites.json` を使う。別の `art/discovery`、PNG生成器、貨物描画器、工具の形状判定を並行運用しない。
- 貨物は既存の共通アトラス、`visibleCargo` の表示優先順位、`cargoMotion` の所有権に一致した受け渡しを維持する。未鑑定品の秘匿、採取済み跡、格子越しのリフト貨物も変更しない。
- 装備比較の CURRENT / CANDIDATE は実際の装備品から選ぶ。現場と同じ `toolSpriteRow` と `work-tools-atlas` の準備ポーズを使い、未装備時は現在の基本道具レベルを反映する。
- D-180 は背景 → 鉱脈・施設外観 → 手掛かり → 作業員・貨物の順に描く。フォールバックの作業員も待機中に採掘せず、工具を二重描画しない。

## 打撃演出

プレイヤーの `MINER_SWING_START` / `MINER_SWING_HIT` / `NODE_DAMAGE` に実際の `depth` を付ける。`MiningImpactEffects` は表示中の階層、実在する地点、正の有限ダメージを持つ `MINER_SWING_HIT` だけを受理する。プレイヤーの岩片は、工具と共通の `miningContact` でイベントの地点に合わせる。別階層の Crew、階層が不明なイベント、待機・歩行から演出を作らない。

岩片260ms・最大16打撃、揺れ110ms・左右1px。階層変更、移動画面、新しいRun、Reboot、描画時計の巻き戻りで破棄する。保存や再抽選はしない。ワールド全体と岩片へ同じ揺れを一度だけ適用し、鑑定・納品・獲得通知とCanvas UIは揺らさない。

## 検証

既存の素材検証・ゲームロジック・操作E2Eを維持する。追加の単体テストは打撃の位置、イベント条件、期限、破棄、件数上限に限定し、装備比較は既存の装備テストを拡張する。固定時刻のブラウザ描画ケース1件でワールド層の共通変位、通知の固定、D-180の重なり順、工具比較の共通画像を確認する。旧アトラス専用の重複テストは残さない。

抽選率・費用・解放条件・物流容量と所要時間・セーブv6は変更しない。人間による初周の楽しさ・実機タッチ・色覚の確認は自動描画検証とは別扱いとする。

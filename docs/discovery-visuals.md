# 発見と貨物の描き分け

PR #16 の発見・品質・初周装備を、数値やラベルだけでなく実際の形で読み取れるようにする描画仕様。抽選率、価格、保証、採掘進捗、物流の所有権、v6セーブ形式は変更しない。

## 地点の手掛かり

`deriveSemanticRenderState().discoveries` の `signal / stage / remaining` を唯一の入力とする。

| signal | SEALED | EXPOSED | SPENT |
| --- | --- | --- | --- |
| METAL | 母岩の小さな金属片 | 大きく露出した鉱塊 | 採取後のくぼみ |
| FOSSIL | 母岩に残る輪郭 | 露出した化石層 | 輪郭の残った抜き跡 |
| RESEARCH | 岩の中の結晶層 | 結晶の束 | 折れた結晶の根元 |

3種類×3段階の20×16ピクセル。活動中の小さな刻みだけが残り破壊回数を示す。通常鉱脈のHPがゼロでも手掛かりは消えず、再生してもSPENTを戻さない。色だけでなく輪郭・面積・陰影を変える。点滅、時間制限、別の抽選、装飾用進行度は加えない。

鉱脈層に描き、人物・貨物の前面には重ねない。D-180の専用鉱脈も同じ層へ移動。D-001の13pxの接地補正と既存の操作領域は保持する。

## 物理貨物

Stone / Iron / Copper / Ancient Alloy のNormal・Fine・Pureは、母岩の塊／大きい面／尖った結晶の形で区別する。色だけに依存しない。既知の三葉虫・アンモナイト・魚・歯・椎骨にはそれぞれ12×10の形を与える。

未鑑定標本は種・保存状態・確定価格より先に判定し、すべて同じ母岩付きの包みとタグを描く。レアな中身だけ特別な見た目にして先に答えを出すことはしない。地上で実際に鑑定されてから、Archiveの既知項目に個別の形を表示する。未発見の図鑑項目は従来の匿名表示を維持する。

床・プレイヤー・Porter・Crew・荷台・中央エレベーター・トロッコ・Freight・Bore出力で同じ選択関数を使用する。小さな搬送機では既存の表示個数上限を維持し、全積載物を描くために所有権や並び順を変えない。画面に重なった大量貨物すべてが一目で識別できる、という保証ではない。

## 装備

装着中のアイテムIDから見た目を導く。インベントリを持っているだけでは装着しない。装備比較のCURRENTとCANDIDATEもそれぞれの実アイテムを使用する。

- Fossil Breaker: 厚い頭部。
- Light Frame: 薄い頭部。
- Research Prism: 結晶色の面。

複数効果の上位工具はFossil → Light → Researchの固定優先順で代表形を選び、全効果の詳細は従来の比較情報で示す。

D-001の追加工具PNGは「通常回収工具・化石・軽量・研究」の4バンク。既存のフレーム別頭部領域だけを編集し、柄・手・採掘姿勢・接地位置を保持する。採掘以外の行は透明。以前の独立した装備オーバーレイは削除し、運搬中や歩行中に別座標のつるはしを描かない。PNGがない深度の描画も同じ工具プロファイルを使う。CrewのD-001画像は既存のレアリティ別バンクを維持する。

回収Pack/Bootsは既存の上位レイヤーを使用し、ランプは姿勢別のヘルメット上の点に描く。全装備の衣服・背負い方を新規制作したものではない。

## 実装と画像制作

`discoveryArt.ts`、`cargoSprites.ts`、`equipmentArt.ts` のピクセル行が形の正。`pixelSprite.ts` で起動時に一度だけ水平の不透明な描画区間へ変換する。フレームごとの画像生成やキャッシュ管理機構は追加しない。手掛かり・品質・標本は画像の読み込みが失敗しても表示できる。

既存のプレイヤー画像は差し替えず、追加工具のみ `player-recovered-tools-atlas.png` に保存。追加PNGが失敗した場合は元の姿勢付き工具へ戻し、人物全体の画像を失敗扱いにしない。

```sh
# 既存の工具アトラスから追加工具だけを再生成
node scripts/field-tool-assets.mjs

# D-001全体の既存生成手順にも追加工具生成を接続
npm run assets:d001
```

ImageMagickは既存と同じ制作時依存であり、通常のビルド・実行・テストに新しい依存はない。追加工具PNGも既存32色パレットと0/255のアルファを使用する。表示用URLの版を更新する。

## 確認範囲

単体テストでは全スプライトの寸法、単色・グレースケールの差、未鑑定情報の非漏洩、画像なしの同一貨物描画、セーブ・再生・時計に依存しない段階、装着と比較の一致を確認する。

E2Eでは390px／1280pxと画像失敗時に、実際のゲームCanvasから品質のピクセルを読み取る。手掛かり9通りも実際のゲームCanvasで検査する。既存の実採掘→段階進行→再読込→採取完了と、初周工具の輸送・装着テストを維持する。追加PNGの柄の不変性・非採掘行の透明性・姿勢別ランプ位置も確認する。実行結果とスクリーンショットはPRのValidationに記録する。

人間によるゲームフィール・混雑時の読みやすさ・実機スマートフォン/Safari・長時間プレイは別途確認が必要。地形の掘り進め、隠し通路、工具別操作方式、全身アニメーションの再制作はこの改修に含めない。
